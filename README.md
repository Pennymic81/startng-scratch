# start.ng Daily Scratch Card

A whimsical design concept for start.ng (HNG community browser games).

The Daily Challenge becomes a recharge-style scratch card. Rub the silver strip with your
mouse or finger to reveal today's goal, then play the game to "load" the card before midnight.

- Single static page: `index.html` (no build step)
- Keyboard and screen reader users get a "Reveal it" button
- Sample data only
- Deploy: drag this folder onto Netlify Drop, or push to GitHub Pages
